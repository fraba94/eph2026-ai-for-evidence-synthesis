Add your screening decisions

A CSV with the columns record_id,decision,reason; decision is include, exclude or unsure. Commas, semicolons or tabs all work, so you can paste straight from a spreadsheet or from the chat.

2

Choose how to count

At title and abstract stage the usual rule is: when in doubt, keep it. A record you never screened is a record you can miss, so by default it counts as excluded.

Optional: add a second run to check reproducibility

Run the same prompt again in a new chat (or with a fresh agent) and paste the second set of decisions. The scorer reports how many records changed.

A good score on a small exercise does not validate a tool. These numbers describe one run, on one set of records, against one reference review. Before using AI in a real review you would need a documented pilot on your own question, reproducibility checks, and a human who verifies every decision.

The beginners track is for learning only. If you are not confident with how large language models work and with advanced techniques, do not use AI to conduct a real evidence review.
